# Agent governance

**Hierarchy:** `resume.md` > verified JD facts > stylistic suggestions

**Allowed:** rephrase, reorder, emphasize, align honest keywords, expand fragments into full sentences

**Forbidden:** new employers, new tools, new certifications, new degrees; dropping base-resume facts; stating what the candidate does not do on the tailored resume or cover letter

**Human gate:** User reviews PR before applying; agent does not auto-submit applications.
