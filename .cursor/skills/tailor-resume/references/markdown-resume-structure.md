# Markdown resume structure

1. Name + contact line
2. Summary (3–4 complete sentences for the tailored version; not keyword soup)
3. Work Experience (reverse chronological)
4. Skills (grouped if helpful)
5. Education

Keep the same sections that exist in `resume.md` (certifications, awards, languages) when they are present.

Job block template:

```markdown
### Title — Company (dates)

- Bullet with metric when available
```

Each bullet is one or two **full sentences**: subject (implied "Led"/"Built" is fine), object, and outcome. Do not write telegraphic fragments, noun piles, or half phrases.

Keep every employer, title, date range, and factual bullet from `resume.md`. Reorder bullets inside a job so JD-relevant work comes first. Reorder skill groups the same way. Do not delete a job or a true bullet to make the page shorter.
